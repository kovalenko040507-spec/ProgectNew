# SuperApp на Python 3.8

## Выбранный UI-фреймворк
PyQt5

Причины:
- стабильный для Python 3.8;
- кроссплатформенность;
- удобная модульная архитектура;
- поддержка графиков и расширяемости.

## Реализовано
- Архитектура SuperApp.
- Главное окно с навигацией.
- Утилита отслеживания курсов валют.
- Заглушки для будущих модулей.
- Модульная структура проекта.
