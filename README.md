## 📓 Заметки (Notes App)

Модуль для создания и управления заметками с поиском и экспортом.

### Возможности:
- ✅ Создание, редактирование и удаление заметок
- ✅ 6 категорий по умолчанию (Общее, Работа, Учёба, Идеи, Важное, Личное)
- ✅ Теги для организации заметок
- ✅ Поиск по тексту заметок
- ✅ Фильтр по категориям
- ✅ Экспорт заметки в Markdown (.md)
- ✅ Экспорт всех заметок в TXT
- ✅ Статистика: количество заметок, слов, символов
- ✅ Сохранение данных в JSON

### Использование:
1. Нажмите " Новая" для создания заметки
2. Введите заголовок, выберите категорию, добавьте теги
3. Напишите содержимое в редакторе
4. Нажмите "💾 Сохранить"
5. Используйте поиск для быстрого нахождения заметок
6. Экспортируйте заметки в Markdown или TXT
